# v0.3 缺陷反馈 brief

更新时间: 2026-06-26T16:54:13-07:00

来源: 用户截图反馈，完整窗口用量看板。

## 结论

本 brief 只定义产品问题、修复要求和验收标准，交给开发工程师实现。当前不要求重写 `engine/` 核心逻辑，不读取或展示对话正文。

本轮必须处理两项:

1. 每日用量柱状图 tooltip 在靠近窗口右侧时被遮挡。
2. 项目分布区域仍显示空态，但本地数据文件已经存在项目维度数据，需要查清活服务和前端集成链路。

## Q-UI-001 每日用量 tooltip 被右边缘遮挡

### 现象

鼠标移到每日用量柱状图右侧边缘的柱子时，tooltip 已出现，但右侧内容被窗口或卡片边缘挡住，用户看不全模型和数值。

### 产品判断

这是前端展示缺陷，不是数据口径问题。当前 tooltip 已经尝试显示在柱子上方，但横向仍以柱子中心定位，靠近边缘时会溢出可见区域。

### 必做要求

- tooltip 必须优先显示在柱子上方。
- 当柱子靠近左侧或右侧边缘时，tooltip 需要自动避让，不得被窗口、卡片或图表容器裁切。
- full view 和 popover view 都要处理。
- tooltip 内容可以换行或限制最大宽度，但不能截断关键数值。

### 建议实现方向

- 优先采用 viewport 或 chart container 边界 clamp。
- 如果现有容器存在 overflow 或层级限制，可以把 tooltip 挂到更高层级或 `body` 上，用 fixed 定位并 clamp 到 viewport 内。
- 不要为了 tooltip 改动图表数据计算逻辑。

### 验收标准

- 在 full view 中 hover 最右侧最高柱，tooltip 完整可见。
- 在 popover view 中 hover 最右侧最高柱，tooltip 完整可见。
- hover 最左侧柱也不会溢出。
- tooltip 不遮挡主导航、项目选择器或下方价格表到不可读。

## Q-UI-002 项目分布仍显示空态

### 现象

完整窗口中选择 `Codex` 后，项目选择器旁显示“暂无项目数据”，项目分布区域显示“暂无项目用量”。

### 已知证据

当前本地 `usage.json` 已包含项目维度数据:

- `projects.length` 大于 0。
- `daily[].byProject` 存在项目 token 汇总。
- 最近日期样例里能看到 `~/个人agent`, `~/ai额度app` 等项目。

因此这不是“engine 完全没有做项目归因”的问题。更可能是运行中的服务、App 打包版本或前端读取的 live JSON 没有吃到新版输出。

### 产品判断

这是集成或运行态缺陷。开发必须先验证活服务返回，而不是只验证磁盘 `usage.json`。

### 必做要求

- 先检查当前 UI 实际请求到的 `/api/usage.json` 是否包含 `projects[]` 和 `daily[].byProject`。
- 如果活服务缺字段，优先确认服务是否是旧进程、旧 bundle 或未重启的数据服务。
- 如果重启或重打包后仍缺字段，再检查 `web/index.html` 的读取、筛选和渲染逻辑。
- 项目分布必须在有项目数据时展示 Top 项目，不允许继续显示空态。
- 项目选择器必须显示项目数量或可选项目，而不是“暂无项目数据”。

### 不做范围

- 不重写 `engine/` 的计费价格表、token 分类、去重、UTC+8、cache write/cache read 口径。
- 不新增读取或展示对话正文。
- 不把完整文件路径默认暴露在可见 UI 中。

### 验收标准

- 活服务 `GET /api/usage.json` 返回的 JSON 中有非空 `projects[]`。
- 活服务 `daily` 中至少一天存在非空 `byProject`。
- 选择 `Codex` 和 `全部` 周期时，项目分布显示非空 Top 项目。
- 项目选择器不再显示“暂无项目数据”。
- 选择某个项目后，首屏数值、每日用量图和 Project Focus 随项目筛选联动。
- full view 和 popover view 都要通过浏览器验证。

## 开发验证建议

必须验证 live UI 数据链路:

- `node --check engine/lib.mjs engine/sources/claude.mjs engine/sources/codex.mjs engine/usage-data.mjs`
- `node engine/usage-data.mjs`
- 启动当前使用的本地服务后，直接请求 `/api/usage.json` 并检查 `projects[]` 和 `daily[].byProject`。
- `./app/build.sh`
- 浏览器验证 full view 和 popover view。
